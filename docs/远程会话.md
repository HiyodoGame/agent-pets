# 跨机器会话（SSH observe）

PetDeck 可以通过 SSH 只读观察远程机器上的 Agent 会话。远程会话会出现在今日页「观察中的会话」，带 `@host` 标记；它们**不可注入**，能力分级为 observe-only，但可以在抽屉里生成并复制交接包。

## 启用

在启动 PetDeck 前设置环境变量（bridge 子进程会继承）：

```bash
# Linux / macOS
export PETDECK_REMOTE_HOSTS="me@build-box,dev2"

# Windows PowerShell（用户级，设置后重启 PetDeck）
[Environment]::SetEnvironmentVariable('PETDECK_REMOTE_HOSTS','me@build-box,dev2','User')
```

多个主机用英文逗号分隔。主机写法为 `host` 或 `user@host`，可使用 `~/.ssh/config` 里的别名。**不要**在值里写 SSH 选项（如 `-oProxyCommand=...`）；包含选项/空白的条目会被忽略。

前提：

- 本机 `ssh` 可用，且已配置免密登录（密钥认证）。
- 远程主机已在 `known_hosts` 中（首次可先手动 `ssh user@host` 确认指纹）。
- 远程主机有 `node` 在 PATH 中（探针通过 `ssh host node -` 运行）。

## 安全边界

- **只读**：探针只读取 `~/.claude/projects` 与 `~/.codex/sessions`，不写任何远程文件，不执行 Agent。
- **无 shell 拼接**：本地以 argv 调起 `ssh`，主机名经过白名单校验（拒绝 `-` 开头与 shell 元字符）；远程命令固定为 `node -`，脚本通过 stdin 传入。
- **严格主机校验**：`BatchMode=yes`（不弹密码）、`StrictHostKeyChecking=yes`（不自动信任新主机）、`ConnectTimeout=8`。
- **超时与隔离**：单主机 25s 超时；一台失败不影响其他主机；全部失败时保留上一次快照并标记 stale。
- **不可注入**：远程会话 `host` 字段让观察抽屉保持只读，只提供转录与交接包复制，不提供注入。

## 覆盖范围与限制

- MVP 探针覆盖 **Claude Code**（`~/.claude/projects/**/*.jsonl`）与 **Codex**（`~/.codex/sessions/**/rollout-*.jsonl`）。
- 每个 Agent 取最新 5 个会话；远程总行数上限 10。
- opencode 依赖本地 serve、zcode/dsh/cursor 等需要更复杂的远程读取，暂未纳入。
- 远程会话的标题、最后消息、状态与 token 用量来自探针输出；不读取完整历史。

## 验证

- 探针可在本地模拟远程执行：
  ```bash
  cat server/remote/probe.mjs | node -
  ```
  输出 JSON 数组；本地已用该方式验证 Claude/Codex 解析。
- 2026-11-20 已完成真实 SSH 端到端验收：本机 127.0.0.1:22 启动真实 ssh2 服务端（ed25519 host key、publickey-only），用真实 `OpenSSH_for_Windows_9.5p1` 客户端经生产 bridge 跑 9/9 场景，覆盖：
  - 成功观察 fixture（Claude/Codex 各 1 行）与真实 `~/.claude` / `~/.codex`（9 行，文件 size+mtime 不变）；
  - host key 不匹配、认证失败均 fail closed，不产出会话行；
  - 好主机 + 死主机失败隔离；总失败后保留 last-known-good 并标记 stale，恢复后 `stale:false`；
  - 不可达目标受 `ConnectTimeout=8` 约束（实测 8,256ms），期间 `/api/health` 仍可用；
  - `inject` 降级为 clipboard，远程 exec 计数不增加。
  报告在 `output/ssh-e2e/report.json`（工作区本地证据，未入库）；方法与环境见[真机实测矩阵](真机实测矩阵.md#2026-11-20-ssh-端到端复核真实协议本机回环)。
- **边界**：本轮服务端是 ssh2，不是 OpenSSH sshd；地址为本机回环，未覆盖独立物理远程机、跨公网/NAT、密码或 keyboard-interactive 认证。远程行没有 cwd/projectId，今日页观察区会按主机聚合；单主机最多 10 行。
