# 自动更新与签名

PetDeck 使用 Tauri 2 updater：桌面版从 GitHub Releases 的 `latest.json` 检查新版本，下载经过 Minisign 签名校验的 NSIS 更新包，用户确认后安装并重启。

## 端点与产物

- 更新端点：`https://github.com/HiyodoGame/agent-pets/releases/latest/download/latest.json`
- **仓库必须为 public**（或更新端点匿名可读）。私有仓库的 release 资源需要鉴权，桌面端更新器无法匿名读取。
- 公钥：写在 `petdeck/src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey`
- 发布产物（由 `.github/workflows/release.yml` / `tauri-action` 生成）：
  - `PetDeck_<version>_x64-setup.exe`（NSIS 安装包）
  - 更新包与 `.sig` 签名
  - `latest.json`（版本、下载地址、签名；公开仓库下使用 GitHub API asset URL，Tauri 更新器会带 `Accept: application/octet-stream` 下载）

## 签名密钥

本机生成的密钥（**不入库**）：

- 私钥：`C:\Users\Con_WKK\.tauri\petdeck-updater.key`
- 公钥：`C:\Users\Con_WKK\.tauri\petdeck-updater.key.pub`（内容已写入 `tauri.conf.json`）
- 密码：`C:\Users\Con_WKK\.tauri\petdeck-updater.password`

需要在 GitHub 仓库 Settings → Secrets and variables → Actions 中添加：

| Secret | 值 |
| --- | --- |
| `TAURI_SIGNING_PRIVATE_KEY` | 私钥文件的完整内容 |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | 上面 `.password` 文件的内容 |

**务必备份私钥与密码。** 丢失后，已安装的客户端将无法验证新版本签名；只能更换密钥并让用户手动重装一次。

> 私钥和密码不得提交到仓库、不得贴进 issue / 日志 / CI 输出。

## 发布流程

1. 修改版本号（三处保持一致）：
   - `petdeck/package.json`
   - `petdeck/src-tauri/Cargo.toml`
   - `petdeck/src-tauri/tauri.conf.json`
2. 提交并推送 `master`，确认 CI 全绿。
3. 打 tag 并推送：
   ```bash
   git tag v0.1.1
   git push origin v0.1.1
   ```
4. `Release` 工作流会构建、签名并创建 GitHub Release，上传 NSIS 安装包、更新包、`.sig` 与 `latest.json`。
5. 在 Release 页面确认 `latest.json` 存在，且版本号与 tag 一致。

## 首次迁移

`v0.1.0` 没有内置 updater，无法自动升级到 `v0.1.1`。用户需要手动下载并安装一次 [v0.1.1](https://github.com/HiyodoGame/agent-pets/releases/tag/v0.1.1)；从 `v0.1.1` 起，后续版本可在应用内更新。

## 本地验证

- 打包含签名更新产物：
  ```bash
  TAURI_SIGNING_PRIVATE_KEY="$(cat <私钥路径>)" \
  TAURI_SIGNING_PRIVATE_KEY_PASSWORD=<密码> \
  npm run tauri:build
  ```
  > Tauri CLI 2.12.4 读取 `TAURI_SIGNING_PRIVATE_KEY` 的内容；`TAURI_SIGNING_PRIVATE_KEY_PATH` 在当前版本未生效。
- 仅验证编译（不打包、不签名）：
  ```bash
  npm run tauri:build -- --no-bundle
  ```
- 真正的端到端升级验证：安装一个较旧的已签名版本 → 发布一个更高版本 → 打开「宠物设置 → 自动更新」确认能发现新版本、安装并重启。该链路依赖已发布的 Release，发布前不能仅靠单测证明。
