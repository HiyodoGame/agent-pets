## 当前计划

### P0：补齐真实发布链路的证据

- [ ] 在真实安装环境完成一次「已签名旧版本 → 更高版本」的应用内更新，记录发现、下载、签名验证、安装与重启结果；当前仅确认 Release 产物和配置存在。
- [ ] 使用至少一台真实 SSH 主机验证 Claude/Codex 远程只读观察、失败隔离与 stale 恢复；当前 SSH 传输链路尚未端到端实测。
- [ ] 在没有预装 Node 24 的干净 Windows 环境验证 NSIS 首启提示；在具备 Gemini CLI 的环境补 observe 实测。结果统一回填[真机实测矩阵](真机实测矩阵.md)。

完成标准：每项都有环境、版本、日期和结果；不能用 fake/spawn 测试代替真机结论。

### P1：处理已确认的体验与工程尾项

- [x] 修复演示模式限流倒计时结束后停在中间态的问题；倒计时结束显示手动重试，已通过纯逻辑测试和真实浏览器验证。
- [x] 已移除未使用的 Seti 字体声明与完整版 Lottie 的 `eval` 警告，并按 Spark/Lottie/KaTeX/Markdown 建立稳定缓存分包；主路由相关包均低于 500 kB。剩余 662 kB 提示来自按需加载的 Mermaid 单一预构建模块，未提高警告阈值。
- [x] 遗留 `review-remediation` worktree 的全部修改与未跟踪文件已保存为 `stash@{0}`（`3c1fbea`）；旧 worktree 和 16 个已合并本地分支已清理，远程分支未改动。

### 候选事项（未进入当前迭代）

以下事项只有经过单独评估并移动到上面的优先级后才执行：

- 内嵌或管理 Node 运行时，降低桌面安装的外部依赖。
- OpenClaw、Antigravity 等新适配器；网页 Agent 注入与 observe-only Agent 的自动注入。
- 更多皮肤、macOS/鸿蒙、团队协作、自动编排与离线指令队列。
- 运行时 schema 校验、更完整的组件渲染/E2E 自动化。
