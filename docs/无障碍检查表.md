# 无障碍检查表

> 适用范围：PetDeck 控制台（今日 / 任务板 / 任务页 / 汇报 / 设置 / 桌宠面板）与桌面端外壳。
> 每次发版前按本表走一遍；「证据」列写实测日期与方式（页面 + 操作），未实测的写「待补」。
> 关联计划：[09-M5-实施计划 W5](重新设计/09-M5-实施计划.md)。

## 1. 键盘路径

- [x] 不接鼠标走完：今日 → 选中任务 → 任务页 → 验收 → 合并授权 → 清理。
- [ ] 任务板每一列、任务行均可 Tab 到达，焦点顺序与视觉顺序一致。
- [ ] 模态（新建项目、新建任务）打开后焦点落在第一个输入框，Tab/Shift+Tab 在对话框内循环，Esc 关闭并把焦点还给触发按钮。
- [ ] 抽屉/面板（桌宠快捷设置、验收面板、合并面板）同样可进可出，不困住焦点。
- [ ] 滚动区（任务事件流）可用键盘滚动，向上触发「加载更早的事件」。

实现位置：`petdeck/src/flows/console/focus-trap.ts`（`useFocusTrap`，首尾循环 + 卸载归还焦点，纯逻辑 `trapTabIndex` 见 `petdeck/src/flows/shared/ui-logic.ts`）；`add-project-dialog.tsx`、`new-task-dialog.tsx` 已接入；表格与列表元素均为原生 `button` / `input` / `a`。

证据：2026-11-22 已在本机 WebView2 用键盘走完验收、合并与清理（21 Tab 到「通过验收」、3 Tab 到「确认合并」、22 Tab 到「清理 worktree」），见[真机实测矩阵](真机实测矩阵.md#2026-11-22-m5-真机验收本机)；未录屏，其余未逐项验证的键盘路径保持未勾选。

## 2. 焦点可见

- [ ] 所有可聚焦元素有可见焦点环，深色与浅色主题都清晰。
- [ ] 焦点环不被 `overflow: hidden` 裁掉（列表首尾行、按钮组）。

实现位置：全局 `:focus-visible` 样式（Spark 令牌）；本周期未改。

证据：待补（截图深浅两套）。

## 3. 对比度

- [ ] 正文、次要文字、禁用态、状态徽标（运行中/待拍板/驳回）在深色与浅色主题下达到 WCAG AA（正文 4.5:1，大字/图标 3:1）。
- [ ] 事件流里的 log.stderr、失败徽标、警告横幅不靠颜色单独表意（同时有图标/文字）。

实现位置：状态与警示条均带图标或文字（`task-bits.tsx`、`interrupt-banner.tsx`、`runtime-status-card.tsx`）。

证据：待补（浅色主题对照表）。

## 4. 缩放 200%

- [ ] 浏览器 200% 缩放（或 1280×720 下的系统缩放）下：任务板九列可横向滚动、任务页事件流与右栏不重叠、设置页卡片不截断。
- [ ] 文字放大后按钮不被裁切，长标题换行而非溢出。

实现位置：布局大量使用 `minmax(0, 1fr)` + `overflow: auto`；本周期给任务板列与产物网格加了 `contain: content`，不改变尺寸计算。

证据：待补（200% 截图 6 页）。

## 5. 减弱动效

- [ ] 系统开启「减少动态效果」后：桌宠待机/拖动动画停止，面板过渡消失，事件流平滑滚动关闭，状态脉冲不再循环。

实现位置：`petdeck/src/styles/pet.css` 与 `app.css` 的 `@media (prefers-reduced-motion: reduce)` 同时把 transition 与 animation 时长压到最小；应用内「动效」开关（`ui-logic.ts` 的 `resolveMotionEnabled`）优先于系统偏好。

证据：待补（开启系统偏好后录屏）。

## 6. 屏幕阅读器与语义

- [ ] 页面标题层级：每页一个 h1，卡片标题 h2，无跳级。
- [ ] 图标按钮均有 `aria-label`（关闭、刷新、复制、导出诊断包、重启本地服务）。
- [ ] 表单控件均有关联 `label`（项目路径、任务标题、Prompt、并发数等）。
- [ ] 任务状态变化经 `aria-live="polite"` 播报（任务页状态行、错误横幅 `role="alert"`）。
- [ ] 纯装饰图形 `aria-hidden="true"`；图片有 `alt`（产物名）。

实现位置：`task-page.tsx` 新增 `role="status"` 状态播报；错误横幅沿用 `role="alert"`；模态 `role="dialog" aria-modal="true" aria-labelledby`。

证据：待补（NVDA 或 Windows 讲述人走一遍任务页）。

## 8. 性能基线（同为 W5 验收）

- [ ] 造 1000 与 5000 事件任务：`node scripts/seed-events.mjs --events 1000`（或 5000），用打印的 `dataDir` 启动 bridge。
- [ ] 任务页首屏 P95 < 1s，滚动 2000 行窗口流畅，内存 < 150 MB。
- [ ] 事件流内存只保留最近 2000 条，向上滚动按 200 条一页拉取，加载后视口位置不跳。

实现：`petdeck/src/flows/console/task-page.tsx`（`EVENTS_WINDOW=2000`、`EVENTS_PAGE=200`、50 ms 合批、`content-visibility: auto`）；服务端 `GET /api/runtime/tasks/:id/events?before=<id>&limit=200`（`petdeck/server/runtime/db.mjs` 的 `eventsBefore`）。

证据：2026-11-22 已完成 5000 事件本机测试，首屏三次 FCP 44/56/40 ms、heap 11.1/12.1/11.0 MB；加载到 2000 条时 heap 14.4 MB，详见[真机实测矩阵](真机实测矩阵.md#2026-11-22-m5-真机验收本机)。1000 事件、严格 P95 与完整滚动回归未做，相关检查项保持未勾选。
