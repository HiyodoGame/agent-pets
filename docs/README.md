# 文档索引

本页是 Agent Pets 文档的统一入口。文档分为「现行说明」「技术参考」「历史记录」三类，历史报告中的待办不自动进入当前开发计划。

## 现行说明

| 文档 | 用途 | 更新时机 |
| --- | --- | --- |
| [根目录 README](../README.md) | 仓库入口、目录分工、从根目录执行的质量检查 | 目录、入口或命令变化时 |
| [petdeck/README.md](../petdeck/README.md) | 开发环境、桌面运行、bridge 配置、适配器概览与质量门 | 开发方式或功能能力变化时 |
| [用户手册](用户手册.md) | 安装、接入、日常使用与故障排查 | 用户可见行为变化时 |
| [真机实测矩阵](真机实测矩阵.md) | 自动化检查与真实 Agent/系统验证证据 | 每次真机复核后 |
| [自动更新与签名](自动更新与签名.md) | 更新签名、发布流程与密钥管理 | 发布链路变化时 |
| [远程会话](远程会话.md) | SSH 只读观察的配置、安全边界与限制 | 远程能力变化时 |
| [统一路线图](ROADMAP.md) | 当前唯一开发计划与优先级 | 计划状态变化时 |
| [CHANGELOG](../CHANGELOG.md) | 已发布版本和未发布变更的事实记录 | 功能变更与发布时 |

宠物美术和皮肤文档位于 [`petdeck/docs/`](../petdeck/docs/)，包括皮肤模板与具体皮肤设计校验记录；它们不承担项目路线图职责。

## 单一事实来源与维护规则

1. **版本**：以 `petdeck/package.json`、`petdeck/src-tauri/Cargo.toml`、`petdeck/src-tauri/tauri.conf.json` 的实现版本为准；发布说明以 `CHANGELOG.md` 为准，不在多份文档重复维护“最新版本”。
2. **能力**：实现以 `petdeck/server/adapters/` 与 `petdeck/server/tiers.mjs` 为准；用户操作见用户手册；是否经过真机验证只以实测矩阵为准。自动化测试通过不等于对应真实 CLI 已验证。
3. **计划**：只有 `docs/ROADMAP.md` 是现行开发计划。新增事项先进入该文件并标明优先级；历史计划保留结论，不继续追加新任务。
4. **链接**：Markdown 使用相对于当前文件的链接。根目录文档在 `docs/`，美术文档在 `petdeck/docs/`，修改路径后必须检查引用。
5. **变更同步**：修改命令、目录、配置、用户可见行为或验证状态时，在同一变更中更新对应现行文档；不要只改历史报告或发布记录。提交前运行 `npm --prefix petdeck run docs:check`，检查 Markdown 本地链接与三处实现版本是否一致。
