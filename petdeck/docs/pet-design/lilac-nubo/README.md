## 交付内容

- `public/pets/lilac-nubo/`：65 张动作帧、代表帧 `preview.png`、`manifest.json`，共 67 个运行时文件。
- `preview.html`：自包含离线动作检查页，支持播放、暂停、逐帧、镜像、深浅背景及 256 / 96 / 82 / 64 px 尺寸。
- `motion-previews/`：11 个保留透明度的 WebP 动作预览；应用仍使用独立 PNG 帧与 manifest 的时序。
- `contact-sheet.png`：11 种动作的代表姿态与小尺寸、深浅底对照。
- `source/`：内置 ImageGen 生成的透明分层图集、9 张提取图层、图层注册与关节配置、完整生成提示词。
- `validation.json`：逐帧边界、尺寸、连续编号、透明度、循环首尾差值、单次动作终帧检查记录。
- `lilac-nubo-skin.zip`：可搬运交付包，含运行时皮肤、离线预览、源图层及复现脚本。

当前工作区已放入 `public/pets/lilac-nubo/`，并将 `lilac-nubo` 追加到 `public/pets/index.json` 的 `skins` 数组。保留原有 default 和其他皮肤。

## 动作设计

| 动作 | 帧数 / fps | 播放 | 表演 |
| --- | --- | --- | --- |
| idle | 8 / 8 | 循环 | 脚底固定，身体轻呼吸、眨眼，卷尾稍后跟随 |
| walk | 8 / 12 | 循环 | 两脚交替抬起和前后摆动，手臂反向摆动；原地行走 |
| sleep | 6 / 6 | 循环 | 闭眼、稍微收身，保持约 94% 身高，缓慢呼吸 |
| drag | 2 / 8 | 循环 | 身体被提起，双脚离开基线，保持温和的小幅晃动 |
| drop | 6 / 12 | 单次 | 下落、接地缓冲、轻回弹、回到标准站姿 |
| pet | 6 / 12 | 单次 | 轻缩肩、眯眼开心，小爪微收，尾巴回应 |
| work | 8 / 12 | 循环 | 小电脑前敲代码，双爪交替接触键盘，身体稳定 |
| think | 6 / 10 | 循环 | 视线抬高、身体轻偏、小爪贴近脸颊 |
| done | 8 / 12 | 单次 | 蓄力、轻跳展开双爪、开心闭眼、落地缓冲、收势 |
| attention | 6 / 10 | 单次 | 看向用户、举爪停留、轻转示意、收手；睁眼不抖动 |
| offline | 1 / 1 | 静态 | 闭眼收爪、卷尾靠近身体、降低饱和度，和睡眠区别 |

单次动作 drop / pet / done / attention 的最后一帧与 idle/0001 完全相同，方便衔接。循环按周期采样，不重复复制首帧到末帧。drag 按规格只有 2 帧，因此主动控制摆幅；它表现被提住的轻摆，不承担复杂的拖起过程。

## 制作方法与复现

使用内置 ImageGen，按已选概念制作透明分层母版，并在 v3 补画独立眼睑原画；没有为每个动画帧重新生成角色。身体与软角保持一体，尾巴、四肢、表情独立注册。Python / Pillow 以 3 倍分辨率做关节旋转、底部固定的呼吸形变、前后层遮挡与眼睑原画替换，再输出完整 256×256 PNG。仅清除低于 8/255 的透明边缘噪点，不自动裁切运行时画布。

环境：Python 3，Pillow（本次使用 12.3.0）。在工程根目录运行：

```powershell
python petdeck/scripts/build-nubo-art.py
```

脚本从其自身路径定位工程，不依赖当前工作目录。若单独解压皮肤包，可在解压根目录运行 `python scripts/build-nubo-art.py`。它会读取包内 `docs/pet-design/lilac-nubo/source/` 并重建导出。
