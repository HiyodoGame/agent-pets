# PetDeck 毛绒小怪物造型探索

本轮是造型探索，不是可加载皮肤。用户已选择毛绒小怪物方向；早期矢量兔、龙、狐方向已撤回，不继续制作。

## 设计定位

像一只住在桌面角落的小生物：柔软、有自己的脾气、会关注工作，但不会不断跳动干扰阅读。造型靠剪影、眼神和身体姿态建立辨识度。采用短绒、简化色块和清楚的四肢，避免毛发细节缩小后变成噪点。

## 三个候选

| 候选 | 造型与性格 | 动作重点 |
| --- | --- | --- |
| 奶团 / oat-momo | 燕麦奶色、梨形身体、短垂耳芽、额头自然毛簇；胆小黏人 | 待机轻呼吸并抬眼；思考歪头贴脸；摸摸时缩肩眯眼，耳尖延迟落下 |
| 蓝噗 / lilac-nubo | 灰蓝紫色、圆角方身体、长短略异的小软角、短尾；好奇活跃 | 目光先动、头再跟随；工作时小爪交替；庆祝时抬爪踮脚，尾巴跟随 |
| 栗困 / russet-dozi | 暖栗色、豆形身体、奶油下巴与肚皮、短卷尾；慵懒可靠 | 半睁眼观察；专注时坐直收爪；睡觉点头并保留身体体积；完成时舒展伸爪 |

上述名称为工作名。概念图上的表情和姿态用于比较设计方向，不代表已经完成动画验证。

## 后续动作制作约定

- 先确定角色标准母版及分层，再制作动作；不逐帧重新生成角色。
- 使用头身、耳角、前后肢、尾巴、表情分层，毛发轮廓固定在所属图层；避免每帧毛发闪烁。
- 主动作由身体重心带动，耳尖和尾巴稍后跟随；循环不重复添加完全相同的末帧。
- idle / walk / work / think 的站立高度起伏控制在 ±4 px。
- work：身体稳定、小爪交替；think：视线上移、歪头贴脸；attention：单次抬爪并看向用户；done：短暂舒展或弹起，末帧稳定。
- sleep 与 offline 保留接近站立的体积；offline 使用静止的闭眼收爪姿态，避免依赖文字或图标。
- 遵循 pet-art-spec-for-codex.md：256×256 RGBA PNG、锚点 (128,224)、朝右、11 个动作共 65 帧、preview 和 manifest。完成前在 96 / 82 / 64 px 下检查。
